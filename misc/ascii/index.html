🔤 ascii filter studio · built for GitHub Pages

Every glyph is a GPU instance: the ramps are baked into a single texture atlas and the whole grid is drawn in one instanced draw call (WebGL2), so the same pipeline can chew through animated GIFs and video frames later without changing a knob. Sampling, dithering and ramp mapping are plain JS — no wasm, no server, nothing leaves your browser.
